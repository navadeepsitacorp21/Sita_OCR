# Sample Reports Documentation

This directory and `/sample_reports` contain mock and anonymized medical lab report samples used to validate the OCR and extraction pipeline.

## Supported Test Formats

1. **CBC (Complete Blood Count)**:
   - Hemoglobin, WBC Count, Platelet Count, RBC Count.
2. **Lipid Profile**:
   - Total Cholesterol, HDL, LDL, Triglycerides.
3. **Thyroid Profile**:
   - T3, T4, TSH.
4. **Metabolic Panel**:
   - Fasting Blood Sugar, HbA1c, Serum Creatinine, Uric Acid.

Place additional sample PDFs or images into the root `sample_reports/` directory for local integration testing.
